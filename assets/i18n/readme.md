# Translation
My website use translations to make sure everyone can read my website, so if you want to translate this into your language, you can!

## How to translate
The website use strings to show translation, that's literally how 99% of websites translate all their text.

Let me show you a example:
```php
return [
    'title' => 'Celeste\'s website!'
```
- The `title` string is the title of what is the text.
- `=>` is the replacer of this string.
- `Celeste\'s website!` is the translation.
