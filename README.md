## How to test
For this, you need [Visual Studio Code](https://code.visualstudio.com/).

### Steps to get it run
1. Clone this repo.
2. Lauch cloned repo with Visual Studio Code.
3. Open `index.php` file.
4. Right-click on it, then `Start/Stop PHP Live Server`.
